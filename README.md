# 花鳥蓋印所

一個以原生 HTML、CSS 與 JavaScript 製作的國風花鳥蓋印小遊戲。

遊戲網址：[https://yikyt-cmd.github.io/Nature/](https://yikyt-cmd.github.io/Nature/)

直接在瀏覽器開啟 `index.html` 開始遊玩：依序選擇花樣並蓋 5 朵花、蓋 5 片葉、選擇雀鳥圖樣並蓋 2 隻小鳥，每個光點停留一秒即可蓋印。紙上的印記與完成後花布中的圖樣都會以隨機且清晰的尺寸呈現；完成後可下載瀏覽器本機生成的 1920 × 1920 無縫重複 JPG，不會上傳圖片或呼叫外部 AI 服務。按「重新開始」可再玩一次。
