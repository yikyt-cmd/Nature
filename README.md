# 花鳥蓋印所

一個以原生 HTML、CSS 與 JavaScript 製作的國風花鳥蓋印小遊戲。

遊戲網址：[https://yikyt-cmd.github.io/Nature/](https://yikyt-cmd.github.io/Nature/)

直接在瀏覽器開啟 `index.html` 開始遊玩：先選花樣並在光點停留一秒蓋 5 朵花，再選葉片圖樣並用滑鼠在白紙上自由描畫（48px 筆刷、葉片間距 5px），按「OK」後選擇雀鳥圖樣並蓋 2 隻小鳥。完成後會把花鳥以 180–300px 隨機尺寸、葉片依照筆刷路徑排成花布，可下載瀏覽器本機生成的 2400 × 2400 JPG；不會上傳圖片或呼叫外部 AI 服務。按「重新開始」可再玩一次。
