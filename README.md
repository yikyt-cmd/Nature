# 花鳥蓋印所

一個以原生 HTML、CSS 與 JavaScript 製作的國風花鳥蓋印小遊戲。

遊戲網址：[https://yikyt-cmd.github.io/Nature/](https://yikyt-cmd.github.io/Nature/)

直接在瀏覽器開啟 `index.html` 開始遊玩：先選葉片圖樣並用滑鼠在白紙上自由描畫（葉片筆刷隨機為 100–200px，葉片間距 5px，不限片數），按「OK」後選花樣並在光點停留一秒蓋 5 朵花，最後選雀鳥圖樣並蓋 2 隻小鳥。花朵依序交替為 300px 和 600px，每隻鳥為 600px。完成後可下載瀏覽器本機生成的 4500 × 4500 JPG：花布會依畫紙上的葉、花、鳥圖案位置與尺寸比例，將整張畫紙圖樣重複排列。光點提示會顯示在葉片上層，不會上傳圖片或呼叫外部 AI 服務。按「重新開始」可再玩一次。
